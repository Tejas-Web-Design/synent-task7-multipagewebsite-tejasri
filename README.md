## 🌟 Overview

Synent Technologies is a modern corporate website designed to showcase technology services, internship opportunities, company expertise, and client engagement through a professional digital experience.

The project focuses on delivering a clean user interface, smooth animations, responsive layouts, and modern web design practices using React and Tailwind CSS.

## 🚀 Installation

Clone the repository:

```bash
git clone https://github.com/yourusername/synent-technologies.git
```

Navigate into the project:

```bash
cd synent-technologies
```

Install dependencies:

```bash
npm install
```

Start development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

### 🎯 Purpose

The purpose of this project was to practice modern frontend development by redesigning a corporate website using contemporary UI/UX principles and modern web technologies.

Inspired by current SaaS and technology company websites, the redesign focuses on creating a clean, responsive, and visually engaging user experience through modern layouts, smooth animations, glassmorphism effects, interactive components, and consistent branding across multiple pages.

This project was developed as a learning and portfolio-building exercise to strengthen skills in React, Tailwind CSS, Framer Motion, responsive design, component-based architecture, and modern website design practices. This redesign was developed as a personal learning and portfolio project to practice modern frontend development, responsive design, and UI/UX principles. The design is inspired by contemporary SaaS and technology websites while maintaining its own unique implementation and branding.
